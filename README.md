# Addons

Installable addons for World of Warcraft 1.12.1 and 1.14.2.

Download one zip and unzip it into `Interface/AddOns`. The zip is that one addon folder.

## 1.12.1

- [Extended Character Stats](1.12.1/ExtendedCharacterStats.zip) — extra combat stats beside the character sheet. Interface 11200. A 1.12 port of [Extended Character Stats 5.5.2](https://github.com/BreakBB/ExtendedCharacterStats) by BreakBB and Ethulu.

## 1.14.2

- [Extended Character Stats](1.14.2/ExtendedCharacterStats.zip) — the same addon for interface 11402.
- [Whisper Dash Fix](1.14.2/WhisperDashFix.zip) — drops the empty realm dash the 1.14 client sometimes adds to a whisper name.
